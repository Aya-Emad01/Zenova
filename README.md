# Zenova

A mobile app concept that helps children and teenagers balance screen time with real-life activities.

Built during the **InnovEgypt** program with **iSpark** (45 hours). The final project was rated **A**, with thanks to TIEC and the instructors.

## The problem

Children aged 8 to 18 spend about 7.5 hours a day on screens. The parental-control software market was worth more than $1.4B in 2024, which shows how many families are looking for a solution.

## The idea

- A mobile app with a gamified "journey" for ages 5 to 18 that rewards real-life activities and balances them with screen time.
- A web dashboard for parents to track usage, set tasks and monitor progress.

## My role

Research and the final presentation. This was a team project.
